FreeLP 0.1.5 simplifies position and wallet management:

- Remove pool details, raw tick ranges, and visible position numbers from portfolio cards.
- Keep long notifications inside the viewport with keyboard-accessible scrolling and a visible dismiss button.
- Hide deployment actions once a contract is deployed.
- Reset an RPC override and close the dialog in one click, with Reset and Save actions side by side.
- Remove the NFT transfer action.
- Add Disconnect wallet to the account menu.

Run `bunx @ekubo/freelp@latest` or `npx @ekubo/freelp@latest`.
